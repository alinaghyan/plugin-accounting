# MaliDev Accounting & ERP

افزونه حسابداری و مدیریت عملیات فروشگاه ووکامرس — نسخه توسعه‌ای

> **هشدار:** این نسخه برای ثبت حسابداری عملیاتی یا صدور فاکتور قانونی تأیید نشده است. پیش از بهره‌برداری باید تست‌های یکپارچه و فشار، بازبینی امنیتی و تطبیق با حسابدار انجام شود.

## وضعیت
- [x] هسته SQLite و مهاجرت نسخه‌بندی‌شده تا schema 4
- [x] مدل طرف‌حساب چندنقشی، کدینگ حساب‌ها و تفصیلی مشتری/تأمین‌کننده
- [x] سرویس سند دوطرفه با توازن و idempotency
- [x] پایه انبار چندگانه، انبار اصلی پیش‌فرض و دفتر گردش تغییرناپذیر موجودی
- [x] ساختار پیش‌نویس فاکتور خرید و ردیف‌های خرید
- [ ] ثبت و قطعی‌سازی فاکتور خرید از UI و سند حسابداری متناظر
- [ ] تخصیص هزینه‌های جانبی خرید و محاسبه میانگین موزون
- [ ] برگشت خرید/مرجوعی و اتصال کامل به بدهی و پرداخت تأمین‌کننده
- [ ] فروش سریع، COGS snapshot و همگام‌سازی WooCommerce/HPOS
- [ ] رزرو، تأمین از شرکت و پیش‌سفارش
- [ ] مهاجرت پارسیان و سامانه مؤدیان

## نصب و پیش‌نیاز
- WordPress 6.3+، PHP 8.1+ و PDO_SQLite فعال
- فضای ذخیره‌سازی خصوصی و قابل پشتیبان‌گیری
- WooCommerce برای قابلیت‌های فروشگاهی فازهای بعدی

دیتابیس در اولویت خارج از web root ذخیره می‌شود. مسیر محافظت‌شده داخل wp-content فقط برای Apache/LiteSpeed/IIS در نظر گرفته می‌شود؛ برای Nginx باید مسیر در سطح سرور deny شود.

## معماری و قواعد
- WooCommerce مرجع سفارش و کاتالوگ؛ Accounting مرجع اسناد مالی و گردش انبار.
- SQLite و MySQL تراکنش مشترک ندارند؛ اتصال فروش فقط با outbox، idempotency، retry و reconciliation فعال خواهد شد.
- مقادیر مالی integer در واحد خرد و مقادیر کالا integer با quantity_scale هستند؛ float برای محاسبات ممنوع.
- گردش‌های انبار append-only هستند؛ اصلاح با گردش معکوس انجام می‌شود.
- فاکتور قطعی خرید حذف یا ویرایش نمی‌شود؛ اصلاح از مسیر سند اصلاحی/معکوس خواهد بود.
- موجودی انبار خودی با موجودی قابل تأمین تأمین‌کننده یکی نیست.
- افزونه‌های دیگر فقط از API عمومی نسخه‌بندی‌شده استفاده خواهند کرد.
