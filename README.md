# MaliDev Accounting & ERP

افزونه حسابداری و مدیریت عملیات فروشگاه ووکامرس — نسخه توسعه‌ای

> **هشدار:** این نسخه برای ثبت حسابداری عملیاتی یا صدور فاکتور قانونی تأیید نشده است. پیش از بهره‌برداری باید تست‌های یکپارچه و فشار، بازبینی امنیتی و تطبیق با حسابدار انجام شود.

## وضعیت
- [x] هسته SQLite و مهاجرت نسخه‌بندی‌شده
- [x] مدل طرف‌حساب چندنقشی و سرویس ایجاد/ویرایش/جست‌وجو/بایگانی
- [x] درخت کدینگ حساب‌ها، حساب‌های پایه و قواعد محافظت از حساب سیستمی
- [x] سرویس ثبت سند دوطرفه با توازن و idempotency
- [ ] رابط کامل مدیریتی طرف‌حساب و کدینگ
- [ ] تفصیلی اشخاص متصل به حساب‌های کنترلی و مانده‌گیری
- [ ] خرید، فروش سریع، میانگین موزون، COGS و گردش انبار
- [ ] همگام‌سازی مقاوم WooCommerce، دریافت/پرداخت و گزارش‌ها
- [ ] مهاجرت پارسیان و سامانه مؤدیان

## نصب و پیش‌نیاز
- WordPress 6.3+، PHP 8.1+ و PDO_SQLite فعال
- فضای ذخیره‌سازی خصوصی و قابل پشتیبان‌گیری
- WooCommerce برای قابلیت‌های فروشگاهی فازهای بعدی

دیتابیس در اولویت خارج از web root ذخیره می‌شود. اگر مسیر خصوصی قابل استفاده نباشد، مسیر محافظت‌شده داخل wp-content تنها در وب‌سرورهای شناخته‌شده Apache/LiteSpeed/IIS در نظر گرفته می‌شود؛ برای Nginx باید مسیر در سطح سرور deny شود.

## معماری
- WooCommerce مرجع سفارش و کاتالوگ؛ Accounting مرجع اسناد مالی، طرف‌حساب و گردش انبار.
- SQLite و MySQL تراکنش مشترک ندارند؛ اتصال فروش فقط با outbox، idempotency، retry و reconciliation فعال خواهد شد.
- مبلغ‌ها integer هستند؛ float برای محاسبات مالی ممنوع.
- اسناد قطعی حذف نمی‌شوند و اصلاح از مسیر سند معکوس انجام می‌شود.
- افزونه‌های دیگر فقط از API عمومی نسخه‌بندی‌شده استفاده خواهند کرد.
